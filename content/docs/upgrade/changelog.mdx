## v0.3.2 - November 7, 2026

### Added
- **RTX PRO 6000 GPU** (96GB VRAM) at $3.94/hr, available on all plans. Select it under **GPU** in your machine settings.
- Support for ComfyUI v0.44.0 (ComfyDeploy custom node v2.3.11)

<Callout type="info">
  If your machine runs ComfyUI v0.44.0, update the ComfyDeploy custom node to the latest version. [Learn how →](/docs/machines/updating)
</Callout>

## v0.3.1 - August 5, 2025

### Added
- Support for ComfyUI v0.3.48

<Callout type="warning">
  Please rebuild your machine and update the ComfyDeploy custom node to the latest version to ensure compatibility with this update. [Learn how →](/docs/machines/updating)
</Callout>


### Breaking Changes
- Workspace sessions require machine rebuild
- **Optimized Cold Start** now requires ComfyUI v0.3.45+

### Action Required
- **Update ComfyDeploy custom node** to latest version
- **Rebuild your machine** if unable to open workspace sessions

[View updating guide →](/docs/machines/updating)
