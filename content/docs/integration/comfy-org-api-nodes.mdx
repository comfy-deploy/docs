## Overview

Connect to the Comfy Org API nodes to use their functionality in your workflows.

Go to https://platform.comfy.org/profile/api-keys to get your API key.

{/* ![Import workflow](/images/data/data-flow-custom-s3.png) */}
![Comfy Org API Nodes](/images/integration/comfy-org-api-key.png)

Copy the API key and go to your ComfyDeploy dashboard. Create a new secret group in your machine settings.
Navigate to the `Secrets` tab and create a new secret group.

![Comfy Org API Nodes](/images/integration/create-secret.png)

Name the secret group `Comfy Org` (up to you).
Make sure to for the key name to use `API_KEY_COMFY_ORG`
Finally paste in the API key you copied from Comfy Org.

Click create and you will be prompted to rebuild the machine. Now you can use the Comfy Org API nodes in your workflows.

![Comfy Org API Nodes](/images/integration/create-secret-group.png)
